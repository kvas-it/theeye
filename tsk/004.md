# Web page crawler (non-RSS sources)

For sources that don't have RSS feeds:

- Fetch the page, extract all links
- Filter links that look like articles (heuristics: path patterns, link text)
- Compare against known URLs in DB
- For new links: download, extract text with `readability-lxml`, store
- This is the "simple path" — if readability works, great. If not, we can
  add per-source extraction logic later.
- Source config can include optional hints:
  - `link_selector` — CSS selector to narrow where to look for links
  - `link_pattern` — regex to filter article URLs
