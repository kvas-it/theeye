# Indicators & dashboards

Future feature: configurable indicators with benchmarks.

Ideas:
- Pull numeric data from APIs (e.g. YFinance for stock prices)
- Define indicators in config with name, source, benchmark value
- Dashboard page showing current value vs benchmark (color-coded)
- Later: derive indicators from article feeds (counts, sentiment)
- Later: aggregate indicators across sources

This is a separate workstream from the feed. Spec out when the feed MVP
is solid.
