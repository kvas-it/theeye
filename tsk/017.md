# Crawl a single URL on demand

CLI command `theeye add <URL>` to crawl a single article directly.

## Behavior

1. If URL already in DB: re-crawl (update title and content_text)
2. Extract text from page (reuse `extract_text`)
3. Match URL hostname to existing source → use that source_id
4. No match → use/create a "Manual" source (catch-all)
5. Insert or update the article

## Notes

- source_id is NOT NULL, so we use a "Manual" source instead of nullable
- Articles under "Manual" can be reassigned later if a matching source is added
- No auto-summarize; next `theeye summarize` picks it up
