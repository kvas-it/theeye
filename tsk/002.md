# Database schema & migrations

Simple versioned migration system:

- `schema_version` table tracking applied migrations
- On startup, scan `migrations/` for `NNN_name.sql` files, apply pending ones
- Initial migration (`001_initial.sql`):
  - `sources` — id, name, url, type (rss/web/forum), config JSON
  - `articles` — id, source_id, url (unique), title, author, content_text,
    discovered_at, published_at
  - `summaries` — id, article_id, summary_title, summary_text, generated_at
  - `notes` — id, article_id, text, created_at, updated_at
  - `read_state` — article_id, read_at
