# RSS/Atom feed crawler

Crawler that processes RSS/Atom sources:

- Read sources from `sources.yaml`
- For RSS/Atom type sources, use `feedparser` to fetch and parse
- For each entry, check if URL already exists in `articles` table
- If new: download article page, extract main text with `readability-lxml`,
  store in DB
- Use `httpx` for HTTP (async-capable for future)
- Handle common edge cases: relative URLs, missing dates, encoding issues
- CLI command: `theeye crawl` — crawls all sources, reports what's new
- Logging: log new articles found, errors per source
