# Project scaffolding

Set up the basic project structure:

- Python project with `pyproject.toml` (or `uv` if preferred)
- Directory layout:
  ```
  theeye/
    config.py        # load YAML config
    db.py            # SQLite connection, migration runner
    crawler/         # crawling logic
    summarizer/      # Claude CLI integration
    web/             # FastAPI app, templates
  migrations/        # numbered SQL files
  templates/         # Jinja2 templates
  sources.yaml       # feed source configuration
  ```
- Dependencies: `fastapi`, `uvicorn`, `jinja2`, `feedparser`, `httpx`,
  `readability-lxml`, `lxml`, `pyyaml`
- Entry points: `theeye crawl`, `theeye summarize`, `theeye serve`
- SQLite database path configurable (default `theeye.db`)
