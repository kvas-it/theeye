# LessWrong GraphQL API as repair path

LessWrong article pages sit behind a Vercel bot checkpoint (429), so we
crawl them from full-post HTML embedded in the RSS feed. That covers new
posts; older posts fall out of the 10-entry feed and can only be
re-fetched via their GraphQL API:

```
POST https://www.lesswrong.com/graphql
{post(input:{selector:{_id:"<id-from-url>"}}){result{title htmlBody}}}
```

Used once on 2026-09-01 to backfill 20 empty articles
(`scripts/backfill_lw.py`). If empty LessWrong articles recur, consider
folding this into `theeye refetch` as a LessWrong-aware mode instead of
running the script by hand.
