# Default feed filter to unread

The feed view should default to showing only unread articles. The user can
still switch to All, Read, or Favorites via the existing dropdown.

- Change the default value of the `status` query param in `feed` route
  from `all` to `unread`.
- Update `_feed_redirect` so it omits the status param when it equals the
  new default (`unread`) instead of `all`.
- Update/add tests to cover the new default behavior.
