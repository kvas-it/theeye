# Throttle fetches & add refetch command

LessWrong started returning 429 during the last crawl, so several
articles ended up in the DB with `content_text IS NULL`. Two changes:

- **Throttle in `fetch_page`**: per-host minimum interval (1.5s) between
  requests, plus a single retry on 429 honoring `Retry-After`.
- **`theeye refetch` CLI**: walks articles whose `content_text` is empty
  and tries to fetch and extract them again. No DB migration — the empty
  body is the marker.

Persistently-failing articles will be retried forever for now; if that
becomes annoying we'll add an attempt counter later.
