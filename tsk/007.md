# Web UI — notes

Ability to attach notes to articles:

- On article detail page, a text area to add/edit a note
- POST `/article/{id}/note` — save note (create or update)
- Notes shown on the article detail page
- Maybe show a "has notes" indicator in the feed list
- Keep it simple: one note per article, plain text (markdown rendering
  would be nice but not required for MVP)
