# Tags

Manual tagging and auto-assignment from existing tags.

- DB: `tags` table (id, name), `article_tags` junction table
- Web UI: show tags on articles, add/remove tags manually
- Summarizer: when summarizing, pass existing tag list to Claude and ask
  it to assign relevant ones (from existing tags only, don't invent new)
- Filter feed by tag
