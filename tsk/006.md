# Web UI — feed view

FastAPI app with Jinja2 templates serving the article feed:

- GET `/` — main feed page, reverse chronological
  - Each item: summary title (or original), author, source name,
    summary paragraph, link to original article
  - Visual indicator for read/unread
  - Pagination or infinite scroll (start with pagination)
- GET `/article/{id}` — article detail view with full extracted text,
  summary, notes
- POST `/article/{id}/read` — mark as read
- POST `/article/{id}/unread` — mark as unread
- Filtering: by source, by read/unread status
- Simple, clean design. Minimal CSS (can use classless CSS framework like
  Simple.css or Pico CSS to start).
