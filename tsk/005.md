# Summarizer via Claude CLI

Batch summarization of unsummarized articles using Claude Code headless:

- Query DB for articles without summaries
- For each article, call `claude` CLI in headless/pipe mode with a prompt:
  - Input: article title, author, source name, article text
  - Output: JSON with `summary_title` (1-sentence informative title, or
    original if already good) and `summary_text` (1 paragraph)
- Store results in `summaries` table
- CLI command: `theeye summarize`
- Options: `--limit N` to cap how many to process in one run
- Error handling: if Claude fails for one article, log and continue
- Designed to run during off-peak hours (overnight free CC slot)
