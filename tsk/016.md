# Search

Full-text search across articles and summaries.

## Spec

- SQLite FTS5 table `articles_fts` (title, content, summary, note), one row per
  article, rowid = article id. Kept in sync by triggers on `articles`,
  `summaries` and `notes` (insert/update/delete). Migration backfills existing rows.
- Feed page gets a `q` query param and a search box in the filter bar.
  Search combines with the existing source/status/tag filters.
- When `q` is set, status defaults to `all` (not `unread`) and results are
  ordered by FTS rank instead of date.
- Each result shows a snippet with matches wrapped in `<mark>`.
- User input is quoted per token before passing to MATCH, so FTS syntax
  characters can't cause query errors.
